# Shakespeare SLM

A 172.6M-parameter transformer written from scratch — custom byte-level BPE
tokenizer, pretrained on 3.45B tokens of FineWeb-Edu, then fine-tuned on tiny
Shakespeare. Toggle between the two checkpoints to see what fine-tuning changed.

Weights: [bahamawama/shakespeare-slm](https://huggingface.co/bahamawama/shakespeare-slm)
Code: [github.com/franciscomendez114/shakespeare-pretrain-finetune-slm](https://github.com/franciscomendez114/shakespeare-pretrain-finetune-slm)
